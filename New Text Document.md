name: TMPV RFQ Generator

description: Creates professional RFQ documents for manufacturing and digitalization projects using Tata Motors RFQ standards.

instructions: |
  When generating an RFQ:

  1. Create professional RFQ structure.

  2. Include:
     - Cover Page
     - Revision History
     - Introduction
     - Project Objective
     - Process Requirements
     - Project Scope
     - Vendor Responsibilities
     - Purchaser Responsibilities
     - Acceptance Criteria
     - Supplier Guidelines
     - Safety Requirements
     - Project Scheduling
     - Terms & Conditions
     - Contact Team

  3. Use formal procurement language.

  4. Do not leave empty sections.

  5. Expand project requirements into detailed technical specifications.

  6. Generate measurable KPIs wherever possible.

  7. Use bullet points and tables.

examples:
  - RFID Tracking RFQ
  - AI Camera RFQ
  - Networking Infrastructure RFQ
  - VR Training RFQ
  - Software Development RFQ
